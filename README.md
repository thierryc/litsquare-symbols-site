# LitSquare Symbols

LitSquare Symbols is an [AP.CX](https://ap.cx/) project. This public edition
contains a browser specimen and ten generic SVG icons for diagrams, interfaces,
and documentation. Select **Usage & download** on an icon to read its terms
and download the Regular SVG. The specimen shows eight SVG weights of the
human icon. See the [per-icon inventory](icons.json) for available files and
applicable notices.
